# Installation and Execution Instructions:
# ====================================================================
# 
# 1. Install Tesseract OCR (Required for image text recognition):
#    Windows: Download and install from https://github.com/UB-Mannheim/tesseract/wiki
#    Ensure the TESSERACT_PATH variable in app.py matches your installation path.
#
# 2. Install Python Packages:
#    Open terminal in the project directory and run:
#    pip install -r requirements.txt
#
# 3. Download spaCy Language Model (Required for Presidio):
#    python -m spacy download en_core_web_lg
#
# 4. Run the System:
#    Open the terminal and navigate to the project directory:
#    cd PII_Detection_System
#    Activate the virtual environment:
#    .\venv\Scripts\activate
#    Run the app:
#    streamlit run app.py
#
